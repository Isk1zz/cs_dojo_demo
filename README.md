# demo_cs_dojo

Practice repo for small self-contained demos.

Open `index.html` in a browser to run it. No build step, no dependencies,
no local server required — double-clicking the file works.

## Running

```bash
git clone https://github.com/lsk1zz/demo_cs_dojo.git
cd demo_cs_dojo
```

Then open `index.html`.

## Notes

This is a learning sandbox, not production code. Expect rough edges,
half-finished ideas, and more than one attempt at the same problem.
